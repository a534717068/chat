Worker 登录测试

这是一个独立测试页面，只测试 Cloudflare Worker 的 /login-test 接口。

它不会保存密码，也不会保存或使用真正的 Session Token。
等待测试……
测试结果说明

如果返回 stage: complete： Worker 的密码验证和 Session 生成正常， 问题就在你的主 index.html 登录流程。

如果返回 stage: password： Worker 收到了密码，但和 APP_PASSWORD 不一致。

如果返回 stage: config： Worker 没有正确读取 APP_PASSWORD 或 SESSION_SECRET。

如果出现浏览器 Fetch / CORS 错误： 说明请求根本没有正常到达 Worker， 需要检查 Worker 的 CORS 设置。
